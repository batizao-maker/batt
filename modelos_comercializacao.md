# Modelos finais de comercialização

Este documento reúne modelos finais de comercialização prontos para uso, com campos preenchíveis, instruções objetivas e checklists de validação.

## Como usar estes modelos

1. Selecione o modelo que melhor representa o seu negócio.
2. Preencha os campos em branco com dados reais.
3. Valide a oferta com o checklist ao final.
4. Revise a proposta com um stakeholder interno antes de enviar ao cliente.

## Checklists finais (use para validação)

**Checklist de proposta**
- [ ] Dor e resultado claros
- [ ] Evidências/estudos de caso
- [ ] Objeções respondidas
- [ ] Próximo passo definido
- [ ] Condições comerciais explícitas
- [ ] Cronograma e responsabilidades claros

**Checklist de operação comercial**
- [ ] CRM configurado
- [ ] Pipeline definido
- [ ] Templates de comunicação
- [ ] Rotina de follow-up
- [ ] SLAs e handoff com time de entrega
